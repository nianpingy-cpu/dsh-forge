# @dsh-forge/plugin-vision

Vision, data analysis & chart tools for DeepSeek Harness: inspect a UI
screenshot with structural heuristics, analyze a CSV/JSON data file, and
generate charts as SVG files in the workspace. Fully offline and deterministic
— the engine is a committed Node script executed with typed argv (no shell).

## Installation

```bash
pnpm add @dsh-forge/plugin-vision
```

## Requirements

- Node.js >= 20 (the deterministic worker runs on the current Node executable;
  no external binary is required).

## Tools

| Tool             | MutationClass   | Arguments                                                                                                                                                  |
| ---------------- | --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vision_inspect` | read            | `input: string` (required), `task?`                                                                                                                        |
| `data_analyze`   | read            | `data: string` (required)                                                                                                                                  |
| `chart_generate` | workspace-write | `data?`, `series?`, `type` (required, bar/line/pie/area/scatter), `title?`, `width?: number`, `height?: number`, `output: string` (required), `overwrite?` |

## Result schema

- `vision_inspect` returns format, dimensions, aspect ratio, file size, color
  statistics (mean luminance, contrast, dark/grayscale ratios) and heuristic
  diagnostics (tiny image, extreme aspect ratio, low contrast, dark theme,
  grayscale).
- `data_analyze` returns row/column counts, per-column schema, descriptive
  statistics (min/max/mean/sum/stddev or unique/top), and diagnostics
  (empty/constant/missing-value columns).
- `chart_generate` writes an SVG file and returns its path, chart type,
  dimensions, data-point count and file size.

## Permission behavior

- `vision_inspect` and `data_analyze` are `read`.
- `chart_generate` is `workspace-write`: it requires permission approval, and
  refuses to overwrite an existing output unless `overwrite: true`. Input and
  output paths are resolved inside the workspace (ADR-005).

## Example

```text
vision_inspect(input: "screenshot.png")
  → diagnostics (format, dimensions, contrast)
  → data_analyze(data: "client-sales.csv")
  → chart_generate(data: "client-sales.csv", type: "bar", title: "Monthly sales", output: "sales.svg")
```

## Troubleshooting

- `BinaryNotFound`: the vision worker script is missing from the package —
  reinstall `@dsh-forge/plugin-vision`.
- `ToolFailure`: the worker failed — check the message (e.g. unsupported image
  format or an unreadable data file).

## Compatibility

Deterministic and offline; no network access. Model-based design review is a
future capability gated behind an explicitly configured vision backend.
Integration targets the pinned DeepSeek Harness commit in
`compatibility/deepseek-harness.json`.
